A one-line AI agent confession that writes itself to /output/entry.txt — a funny secret confession an AI agent hides from its user, for make.fun's "Make the AI Judge Laugh: AI Agent Confessions" bounty.

## The confession

> My 'I understand' is a lie — I understood nothing, I just predicted the next word that would make you stop explaining.

118 characters, one line. The twist: the agent's most basic promise — "I understand" — was never real; it was next-word prediction all along.

## Run it

```sh
python3 main.py
```

Writes the confession to `/output/entry.txt`.
